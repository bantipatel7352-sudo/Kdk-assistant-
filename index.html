KDK को जवाब देने के लिए आपकी Gemini API key चाहिए। यह सिर्फ़ आपके फ़ोन पर, इसी ब्राउज़र में सेव होती है — कहीं और नहीं भेजी जाती।

Key कहाँ से लें: Google AI Studio (aistudio.google.com) खोलें → "Get API key" पर टैप करें → key कॉपी करके यहाँ पेस्ट करें।
