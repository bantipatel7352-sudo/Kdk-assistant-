यह ब्राउज़र सपोर्ट नहीं करता

आवाज़ पहचानने के लिए कृपया Android पर Chrome ब्राउज़र में यह पेज खोलें।

Jaanu में आपका स्वागत है

Jaanu डिफ़ॉल्ट रूप से बिना किसी cloud API के, सिर्फ़ कमांड्स के ज़रिए काम करती है — YouTube खोलना, कॉल करना, समय बताना वगैरह तुरंत काम करेगा। बातचीत के लिए बाद में Settings में अपना खुद का cloud server जोड़ सकते हैं।
